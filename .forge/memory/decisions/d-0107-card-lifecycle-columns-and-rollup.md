statement: Board columns follow the card lifecycle, not its type (type is an icon) - New (just arrived), Shaping (Director and user discussing or planning), Needs you (anything waiting on the user - plan approval, question, merge hold, outsider's issue awaiting approval), In progress (any linked ticket running, gated or in an open PR), Done (all linked tickets merged or discussion resolved; the linked GitHub issue closes), Closed (dropped, duplicate, not actionable, with a reason). A card's column is rolled up from its tickets and pending interactions, never moved by hand - Needs you wins over everything, then In progress; Done when all tickets merged; a Discussion card stays in Shaping until converted or closed.
