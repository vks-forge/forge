summary: 'E2B''s published pricing page (vendor primary source, utility for sandbox-per-agent
  cost modeling). Hobby tier: free, $100 one-time usage credit, sessions up to 1 hour,
  20 concurrent sandboxes. Pro tier: $150/month base + usage billed per second, sessions
  up to 24 hours, 100 concurrent sandboxes (expandable to 1,100 via add-ons: +$500/mo
  for 600 concurrent, +$1,000/mo for 1,100 concurrent). Enterprise: custom, $3,000/mo
  minimum, tens of thousands of concurrent sandboxes, multi-day/persistent sessions,
  BYOC. Worked example from E2B''s own calculator: default config (2 vCPU, 4GiB RAM)
  at 1,000 run-hours/month (e.g. 100 sandboxes x 10 hrs) = $166 usage + $150 Pro base
  = $316/month total for 100 concurrent sandboxes. Per-second compute rates: vCPU
  $0.000014/s per core (so 2 vCPU default = $0.000028/s), memory $0.0000045/s per
  GiB (4GiB default = $0.000018/s). Storage: 10-20GB free depending on tier. 1B+ sandboxes
  started to date (vendor claim).'
