summary: 'SOURCE HUB — companion repo to IJCAI 2024 survey ''Large Language Model
  based Multi-Agents: A Survey of Progress and Challenges'' (Taicheng Guo et al.,
  arXiv:2402.01680, 1.3k GitHub stars). Curated, actively updated (entries through
  2026/07) bibliography organized into 5 streams: Multi-Agent Framework (AutoGen,
  MetaGPT, CAMEL, AgentVerse, AutoAgents), Multi-Agent Orchestration and Efficiency
  (crewAI, Language Agents as Optimizable Graphs, Actor-Critic decision-making, CORAL/CoMAS
  2025-2026 entries on autonomous multi-agent evolution), Multi-Agent for Problem
  Solving (software development subsection: AgentCoder, L2MAC, MetaGPT, ChatDev/''Communicative
  agents for software development'', Self-collaboration Code Generation), World Simulation,
  and Datasets/Benchmarks (SOTOPIA, MAgIC, LLMArena, PerspectiveGap). Each entry gives
  exact date, title, authors, and paper/code links — a load-bearing index for locating
  primary sources on orchestration, debate/consensus (ChatEval, multiagent debate),
  and coding-agent frameworks. Not itself citable as a primary finding; use to chase
  specific papers (e.g., arXiv:2402.01680 for the survey itself, AgentCoder, L2MAC,
  MetaGPT for software-dev multi-agent architectures).'
